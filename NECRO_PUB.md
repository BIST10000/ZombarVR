# НЕКРО-ПАБ — VR-прототип для Meta Quest

Проект: Unity 6000.6.5f1, URP, OpenXR, XR Interaction Toolkit. Главная сцена: `Assets/Scenes/ZombieBar.unity`.

## Игровой цикл

Прочитайте заказ над клиентом. Выберите один из трёх рецептов на стойке, затем действие «ОТДАТЬ» у нужного клиента. Верный заказ приносит жетоны, неверный уменьшает терпение. Новый коктейль нельзя приготовить, пока не отдан предыдущий.

| Коктейль | Ингредиенты |
| --- | --- |
| Кровавый флип | 1 кровь + 1 глаз |
| Гнилой сауэр | 1 плоть + 1 кровь |
| Глазной хайбол | 1 плоть + 1 глаз |

Помощник слева бесплатно даёт плоть, кости, глаза и кровь. Рука восстанавливается за 16 секунд, глаз за 12, кровь за 8. Рука и глаз временно исчезают с модели. Восстановление тела бармена стоит 2 порции крови и возвращает руки, зрение и здоровье.

Разозлённые клиенты атакуют и могут поджечь бар. Первые травмы отключают одну руку и сужают обзор; третий удар завершает смену. Обычного зомби можно победить действием «УДАР», затем переработать действием «ДОБЫТЬ». Между ударами есть задержка. Титанов победить нельзя — обслуживайте их вовремя. Они появляются после первых трёх успешных заказов.

Пожар тушится одной порцией крови. Потоп устраняется тремя нажатиями насоса; улучшенный насос работает быстрее. За жетоны доступны качество напитков, сила, холодильник, спринклер и насос. Холодильник увеличивает выход плоти, спринклер даёт дополнительное время на пожар. Иногда приходит торговец ингредиентами.

## Управление

- **Quest:** направьте луч контроллера на станцию/клиента и нажмите курок. После поражения нажмите A или X — клавиатура не нужна.
- **Редактор без шлема:** WASD — перемещение, правая кнопка мыши — обзор, E/левая кнопка — действие по центру взгляда, Q — ближайшая станция, R — новая смена после поражения.
- Повреждённая VR-рука перестаёт выполнять игровые действия. Кнопки перезапуска продолжают работать.

## Сборка

В Unity: **НЕКРО-ПАБ → Настроить Meta Quest**, затем **НЕКРО-ПАБ → Собрать APK для Meta Quest**. Сборщик использует только сцену бара. Выходной файл: `Builds/Quest/NecroPub.apk`.

Конфигурация: Android, ARM64, IL2CPP, Vulkan, OpenXR Single Pass Instanced/Multi-view, Meta Quest и профили Touch. Android Build Support, SDK, NDK и OpenJDK должны быть установлены в используемом редакторе. APK предназначен для локальной установки; публикация в магазине не настроена.

## Проверки и границы прототипа

`ZombarEditor.BarSmokeChecks.Run()` выполняет восемь сценариев на запущенной сцене. Проверяются заказы, травмы и лечение, регенерация, бой и титан, добыча, аварии, покупки и перезапуск. Отчёт пишется в `Builds/Validation/gameplay-checks.txt`.

`ZombarEditor.BarBatchValidation.Run()` запускает сцену в пакетном режиме, проверяет продвижение кадров, выполняет сценарии и сохраняет кадр `Builds/Validation/necro-pub.png`. Метод сам завершает редактор; запускайте отдельным процессом без `-quit`.

Это прототип с процедурными моделями и взаимодействием через лучи/станции. Свободное физическое смешивание жидкостей, захват и отрывание частей тела руками, сохранение прогресса между запусками и полноценная кампания ещё не реализованы. Новая смена сбрасывает экономику и улучшения. Плавность, стереоскопический комфорт и работу контроллеров нужно проверить на физическом Quest; проверки в редакторе этого не подтверждают.
