# Редактирование окружения

Предметы в руках бармена находятся в BloodFlask.blend, Hatchet.blend и CocktailShaker.blend. После экспорта соответствующих FBX выберите «НЕКРО-ПАБ → Обновить предметы бармена». Bottle.blend содержит декоративную винную бутылку для стойки.

Откройте нужный .blend: Counter — стойка, Window — окно, Bottle — игровая бутылка, Glass — бокал, Pendant — подвесной светильник, Lantern — настольный фонарь, Backbar — полка с посудой, Stool — табурет, Barrel — бочка, Cabinet — шкаф, Tray — поднос.

Текстуры упакованы в файлы. Источники и лицензии: Assets/Zombar/Art/External/Environment/PROVENANCE.md.

Экспортируйте меши через File → Export → FBX в Assets/Zombar/Art/External/Environment под тем же именем. Forward -Z, Up Y, Bake Animation выключен. Сохраняйте имена материалов. Затем в Unity выберите НЕКРО-ПАБ → Обновить модели окружения CC0.

У игровых бутылки и бокала начало координат находится на дне; высота бутылки 0,28 м, бокала 0,18 м. Эти размеры связаны с зонами наливания. Текстуры в .blend и отдельные PNG в Unity редактируются независимо.
