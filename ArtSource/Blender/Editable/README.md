# Как править модели

Откройте Zombie_Male.blend (фуражка), Zombie_Female.blend (капюшон) или BarProps.blend в Blender 5.2.3. В персонажах коллекция Face details содержит отдельные объекты век, зубов, глаз, швов и головного убора. Face sculpt — более плотная исходная сетка лица для Sculpt Mode. Пальто и рукава привязаны к костям. Для изменения позы выберите скелет и включите Pose Mode. Текстуры упакованы в файлы.

В BarProps.blend предметы разложены по коллекциям. Перед экспортом выделите деталь именно того предмета, который редактировали. Оставьте пустышку origin на месте, она задаёт точку захвата.

1. Сохраните свою работу клавишами Ctrl+S.
2. Откройте рабочее пространство Scripting. В выпадающем списке Text Editor выберите **Export to Unity.py**. Наведите курсор на текст скрипта и нажмите Alt+P (Run Script).
3. Переключитесь в Unity. Редактор переимпортирует FBX с прежним путём и GUID, поэтому персонаж или предмет обновится в сцене ZombieBar.

Экспорт персонажа записывает Assets/Zombar/Art/Characters/Adapted/Zombie_Male.fbx или Zombie_Female.fbx. Для реквизита обновляется один FBX в Assets/Zombar/Resources/PhysicalBar/Models/. При экспорте лицо упрощается и объединяется на временной копии. Детали в .blend сохраняются раздельными. Сохраняйте файлы под исходными именами в папке Editable, чтобы скрипт нашёл проект.

Для изменения игровой текстуры в Texture Paint сохраните PNG через Image → Save As поверх соответствующего файла в Assets/Zombar/Art/Characters/PortraitMaps/. Упакованные изображения .blend и используемые Unity PNG сохраняются отдельно. Имена костей и материалов используются префабами и привязками игры.
